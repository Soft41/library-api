Проєкт виконано як лабораторну роботу
**«Документування API за допомогою OpenAPI та Zudoku»**.

- **Автор:** Soft41
- **GitHub:** [github.com/Soft41](https://github.com/Soft41)
- **Варіант:** Library system — сутності Book, Author

## Що зроблено

1. Спроєктовано REST API бібліотечної системи з CRUD-операціями для авторів і книг.
2. API описано в OpenAPI 3.0.3 (YAML).
3. За допомогою OpenAPI Generator згенеровано SDK-клієнт на TypeScript (Axios).
4. Специфікацію та SDK завантажено в репозиторій
   [Soft41/library-api](https://github.com/Soft41/library-api).
5. Створено цей сайт документації на [Zudoku](https://zudoku.dev) та розгорнуто на GitHub Pages.
