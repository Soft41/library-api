Library System API

REST API бібліотечної системи. Дозволяє керувати авторами (Author) та книгами (Book): створювати, переглядати, оновлювати та видаляти записи.

Усі запити, крім GET, потребують авторизації за JWT-токеном (заголовок Authorization: Bearer <token>).
